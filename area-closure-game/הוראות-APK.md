**https://samuel052.github.io/cgm-remote-monitor/**

בזכות זה אפשר לייצר ממנו קובץ APK אמיתי לאנדרואיד בכמה דקות, בחינם, ובלי לכתוב שורת קוד.

## דרך א' — PWABuilder (מומלץ! בלי להתקין כלום) ⭐

1. גולשים במחשב או בנייד אל: **https://www.pwabuilder.com**
2. מדביקים בתיבה את כתובת המשחק:
   `https://samuel052.github.io/cgm-remote-monitor/`
   ולוחצים **Start**.
3. האתר יסרוק את המשחק ויציג ציון. לוחצים על **Package For Stores**.
4. בוחרים **Android** ולוחצים **Generate Package**.
5. אפשר להשאיר את ברירות המחדל, או להתאים:
   - **App name:** סוגר השטחים
   - **Package ID:** למשל `com.samuel052.sogerhashtahim`
6. לוחצים **Download** — מתקבל קובץ ZIP ובתוכו:
   - קובץ **`.apk`** — להתקנה ישירה בטלפון ולשיתוף מטלפון לטלפון 📲
   - קובץ **`.aab`** — אם תרצו אי־פעם להעלות לחנות Google Play
   - קובץ **`assetlinks.json`** — ראו סעיף "מסך מלא" בהמשך

### התקנת ה־APK בטלפון

1. מעבירים את קובץ ה־APK לטלפון (וואטסאפ / מייל / כבל / דרייב).
2. פותחים את הקובץ בטלפון.
3. אנדרואיד יבקש אישור **"התקנה מאפליקציות לא מוכרות"** — מאשרים (זה מופיע רק בפעם הראשונה).
4. זהו! האפליקציה על מסך הבית עם האייקון של המשחק. 🎮

### שדרוג אופציונלי — מסך מלא בלי פס דפדפן

בלי הצעד הזה המשחק יעבוד מצוין, אבל יופיע פס דק של הדפדפן למעלה. כדי להעלים אותו:

1. ב־GitHub יוצרים ריפו (מאגר) חדש בשם **`samuel052.github.io`** (בדיוק בשם הזה).
2. מעלים לתוכו את הקובץ `assetlinks.json` שקיבלתם מ־PWABuilder, בנתיב:
   `.well-known/assetlinks.json`
3. ממתינים כמה דקות ומתקינים את ה־APK מחדש — עכשיו במסך מלא אמיתי.

## דרך ב' — Capacitor + Android Studio (למי שרוצה בנייה מקומית מלאה)

מתאים למי שמתכנת ורוצה שליטה מלאה. דרוש מחשב עם [Android Studio](https://developer.android.com/studio) ו־Node.js:

```bash
cd area-closure-game
npm init -y
npm install @capacitor/core @capacitor/cli
npx cap init "סוגר השטחים" com.samuel052.sogerhashtahim --web-dir=.
npx cap add android
npx cap open android
```

ב־Android Studio: **Build ← Build Bundle(s) / APK(s) ← Build APK(s)** — וקובץ ה־APK ממתין בתיקיית `app/build/outputs/apk/debug/`.

## תזכורת — לא חייבים APK בכלל 😉

- **אנדרואיד:** פותחים את הקישור בכרום ← תפריט ⋮ ← **"הוספה למסך הבית" / "התקנת אפליקציה"** — מקבלים אפליקציה במסך מלא שעובדת גם בלי אינטרנט.
- **אייפון:** ל־iOS אין קבצי APK בכלל; פותחים את הקישור בספארי ← שיתוף ← **"הוסף למסך הבית"**.
- **העברה מטלפון לטלפון בלי אינטרנט:** משתפים את הקובץ הבודד `soger-hashtahim.html` — כל המשחק בקובץ אחד.
