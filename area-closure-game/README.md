# 🎮 סוגר השטחים — Area Closer

משחק סגירת שטחים חינני בסגנון Xonix/Qix — **10 שלבים**, בנוי כ־PWA (Progressive Web App) שמתקינים על מסך הבית של הנייד ומשחקים גם בלי אינטרנט.

## איך משחקים

- **מטרה:** לסגור אחוז יעד מהשטח בכל שלב (70%–85%).
- **תנועה:** החלקת אצבע בנייד (למעלה/למטה/ימינה/שמאלה) או חצים/WASD במקלדת.
- יוצאים מהמסגרת הבטוחה אל "הים", מציירים קו זוהר, וחוזרים למסגרת — כל אזור שנסגר בלי כדור בתוכו הופך לשטח שלכם.
- **סכנות:** כדורים ורודים שנוגעים בקו שלכם (או בכם), חציית הקו של עצמכם, ושומרי גבול זהובים שמסתובבים על השטח הכבוש.
- **ניקוד:** נקודות על כל תא שנסגר, מכפילים (×2/×3/×4) על סגירות גדולות, ובונוסים על זמן, חיים ושטח עודף. עד ⭐⭐⭐ לכל שלב, שיא נשמר במכשיר.

## הרצה מקומית

```bash
cd area-closure-game
npx serve .          # או: python3 -m http.server 8080
```

ופותחים את `http://localhost:8080` בדפדפן.

## התקנה כאפליקציה בנייד 📱

יש להגיש את התיקייה מכתובת **HTTPS** (למשל GitHub Pages, Netlify או Vercel — גרירת התיקייה מספיקה), ואז:

- **אנדרואיד (Chrome):** פותחים את הכתובת → תפריט ⋮ → **"הוספה למסך הבית" / "התקנת אפליקציה"**.
- **אייפון (Safari):** פותחים את הכתובת → כפתור שיתוף → **"הוסף למסך הבית"**.

האפליקציה נפתחת במסך מלא, עובדת אופליין (service worker), ושומרת התקדמות ושיאים במכשיר.

## אריזה כאפליקציה "אמיתית" (אופציונלי)

להעלאה לחנויות אפשר לעטוף את התיקייה עם [Capacitor](https://capacitorjs.com):

```bash
npm init -y && npm i @capacitor/core @capacitor/cli
npx cap init "סוגר השטחים" com.example.areacloser --web-dir=.
npx cap add android   # או ios
npx cap open android
```

## קבצים

| קובץ | תפקיד |
|---|---|
| `index.html` | המשחק כולו — לוגיקה, גרפיקה (Canvas), צלילים (WebAudio) וממשק |

| `sw.js` | Service worker למשחק אופליין |
